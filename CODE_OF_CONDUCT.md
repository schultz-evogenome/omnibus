# Code of conduct

Adapted from bioconda's.

- Be respectful.
- Be welcoming.
- Be considerate.
- Focus on what is best for the community.
- Accept constructive criticism gracefully.
- Show courtesy and respect towards other community members.
- Respect different viewpoints and experiences.
- Use welcoming and inclusive language.

## Reporting

If you see a violation, report it to a core member. Core members are listed
in `.github/CODEOWNERS`; their contact details are on their GitHub and ORCID
profiles.

## Enforcement

On receiving a report, the core team discusses it privately and decides on a
response. Possible responses:

- no further action, if no violation occurred;
- a private reprimand, delivered by a core member by email with the rest of
  the core team copied;
- a public reprimand, in the thread where the violation occurred;
- a temporary or permanent ban from the repository and its discussions.

The person who reported is told what was decided.
